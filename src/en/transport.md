## 1. Tram (Tranvía)

The tram is the most convenient tool in Murcia. It has one main line (L1).

{% grid %}
{% card "💰 Fare Information" %}
| Ticket | Price |
|---|---|
| Single Ticket (Zona 1 / 2) | 1.4€ / 1.5€ |
| **Multi-card (Bono)** | 0.5€ / trip |
| **Student Pass** | 12€ / 28 days |
{% endcard %}
