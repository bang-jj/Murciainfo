## 1. 中心部と近郊（トラム・バスで行ける）

{% grid %}
{% figure "../images/places/cathedral.jpg", "ムルシア大聖堂" %}
{% figure "../images/places/real-casino.jpg", "レアル・カジノの内部" %}
{% endgrid %}

{% card "🏛️ 文化とランドマーク" %}
- **ムルシア大聖堂（Catedral de Murcia）：** {% tag "開館中は無料で入場可、ガイドツアーと鐘楼は有料", "price" %} 街のシンボル。大聖堂と鐘楼のツアーは別売りで、ガイドは **スペイン語のみ** です。
- **レアル・カジノ（Real Casino de Murcia）：** {% tag "有料", "price" %} かつての上流階級のクラブを改装した博物館。イスラムとヨーロッパの様式が融合した内装はとても豪華で、写真映えします。
- **博物館：** **Museo de Santa Clara**（修道院遺跡）や **Museo Arqueológico**（考古学博物館）など。サンタ・クララは開館時間内なら無料で入れます。ほかにもたくさんの博物館があります。
- **モンテアグード城（キリスト像）：** {% tag "バス 22 / 50番" %} 丘の上にそびえる巨大なキリスト像。現在は遠くから眺めるか麓までしか行けませんが、ムルシアで最も有名な景色の一つで、夕日を見るのにぴったりです。
- **UMU 水族館（Acuario）：** {% tag "約1€", "price" %} Cuartel de Artillería にある、ムルシア大学が運営する小さくて素敵な水族館。

### 🛍️ ショッピングとレジャー

- **エル・コルテ・イングレス（El Corte Inglés）：** 中心部のデパート。上質なお土産の売り場もあります。
- **IKEA / Nueva Condomina：** {% tag "トラム終点" %} 最大のショッピングエリア。服のブランドがそろい、映画館、家電店、ファストフードもあります。
- **Casa del Libro：** 市内の書店。ただし英語の本は棚1つ分だけです。
- **Jardín del Salitre：** ムルシアには散歩できる公園や庭園がたくさんあり、ここはその一つ。家の近くや珍しい植物のある所を選ぶとよいでしょう。

### 🌃 ナイトライフと交流

- **Taboo Bar：** ESN（ヨーロッパの国際学生団体）がよくイベントを開くバー。UM と UCAM の学生とたくさん知り合えます。
- **Karaoke La Gramola Centro：** カラオケですが、日本のような個室ではありません。外向的で歌って友達を作りたい人におすすめ。
- **ODISEO：** {% tag "トラム／タクシー" %} ムルシアの高級複合エンタメ施設。有名なクラブ、レストラン、カジノがあり、とてもモダンな内装です。知り合いと一緒に行くほうが入りやすいようです。
{% endcard %}

## 2. 郊外の見どころ（バス・鉄道で）

{% grid %}
{% card "🌊 カルタヘナ（Cartagena）" %}
{% tag "ALSA バス / FEVE 鉄道" %} 古代ローマの遺跡が残る港町。昼間に港を散歩するのがとても気持ちよく、のんびり1日過ごせます。
{% endcard %}
{% card "🏖️ アギラス（Águilas）" %}
{% tag "鉄道 C-2 線" %} 美しいビーチがあり、スペイン有数の **カーニバル（Carnaval）** で有名です。
{% endcard %}
{% card "🍷 フミーリャ / ブーリャス" %}
{% tag "バス" %} ワインの名産地。フミーリャはワイナリー見学で有名、ブーリャスでは天然の滝 **Salto del Usero** がおすすめです。
{% endcard %}
{% card "🌸 シエサ（Cieza）" %}
{% tag "バス／鉄道" %} 毎年2〜3月の桃の花（**La Floración**）の季節は絶景で、ハイキングに最適です。
{% endcard %}
{% card "🌴 アリカンテ（Alicante）" %}
{% tag "鉄道／バス" %} 近くの大都市。美しい海岸遊歩道で日の出を見たり、高台の **サンタ・バルバラ城** に登ったりできます。
{% endcard %}
{% endgrid %}
