## 1. トラム（Tranvía）

トラムはムルシアで最も便利な交通手段です。路線は1本（L1）だけで、留学生がよく行く場所のほとんどをカバーしています。

{% figure "../images/places/tram.jpg", "ムルシアのトラム" %}

| 片道券（Zona 1 / Zona 2） | 1.4€ / 1.5€ |
| **共通交通カード（Bono Multitransporte）** | 0.5€ / 回 |
| **学生定期（Bono Campus）** | 12€ / 28日間乗り放題 |

{% alert "⚠️ 乗り換えに注意：" %}
大学（Universidad）方面に向かう場合、UCAM の学生は **Los Rectores-Terra Natura** で降りて、**UCAM - Los Jerónimos** 行きの支線に乗り換える必要があります。帰りも同じです（たまに直通便もあります）。
{% endalert %}

## 2. バス（Autobús）

バスは少し複雑で、市内バス（TMurciaBus）と郊外バス（TMP）の2つのシステムがあります。

- **共通交通カードでの運賃：** 1回 **0.8€**。
- **見分け方：** 車両の前に **R** と書いてあるものは、たいてい市内バスです。
- **UCAM へ：** 44番か33番のバス。

{% alert "🚨 注意：" %}
1. 行き先表示に **UCAM - Los Jerónimos** とあるか必ず確認しましょう。例えば 44E は移民局方面で、大学には行きません。
2. バスはよく遅れたり来なかったりします。Google マップの情報も完全には正確ではありません。
{% endalert %}
