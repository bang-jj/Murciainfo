## 1. 外食

スペインのレストランは15〜20€かかることも多いので、留学生は普段ファストフード、ケバブ、スーパーの電子レンジ食品などで済ませることが多いです。

{% card "🍔 ファストフード <small>（平均 8〜10€）</small>" %}
- **Plaza Circular 周辺：** Popeyes、KFC、Burger King があります。エル・コルテ・イングレス近くの BK は若者が多く、サービスは普通です。
- **Senda de Granada：** カルフール横の BK は中心部より落ち着いています。
- **McDonald's：** ショッピングモール方面（Churra 駅）。クーポンがあるので **アプリのダウンロードがおすすめ** です。ドリンクのおかわりはできません。
- **その他：** IKEA（Príncipe Felipe 駅）や Taco Bell も比較的安い選択肢です。

### 🌯 ケバブ <small>（10€以下ならこれ）</small>

街中どこにでもあります。おすすめは **Hakan、Musa、Mundo Kebab**。セットはメイン（ピタ／ボックスなど）、ポテト、ドリンク付きで、量が多くハズレがありません。

### 🍕 中価格帯・お祝い向け <small>（平均 12〜20€以上）</small>

- **ピザ／パスタ：** La Pierotti Pizzeria、Mano a mano。
- **みんなで行くなら：** Anari Sushi（食べ放題）、MISO（和食食べ放題）、火鍋の大龍焱（DaLongYi）。
{% endcard %}

## 2. スーパーと自炊

{% alert "⚠️ 重要：" %}
カルフール（Carrefour）以外の地元スーパー（Mercadona、Lidl など）は **日曜日と祝日はすべて休み** です。前もって買いだめしておきましょう。
{% endalert %}

{% card "🛒 地元のスーパー" %}
Mercadona、Día、Consum、Lidl、El Corte Inglés。油、塩、米、じゃがいも、キャベツなどの基本的な食材は簡単に手に入ります。

### 🏮 アジア系スーパー

日本食の材料は、中国系のアジアスーパーでかなり手に入ります：

- **Hello Asia：** 中心部、Plaza Circular から徒歩10分。
- **Happy Dulce（糖家福）：** 44番バスの路線沿い。行きやすいです。
- **Wan Ka Le（萬家樂）：** 郊外。30番バスで行きます。
{% endcard %}

{% card "🍙 日本食について" %}
- **見つかりやすいもの：** 醤油、米（短粒米・寿司用米）、豆腐、海苔、インスタント麺、冷凍餃子、緑茶など。味噌やだしなど日本の特定商品は、店や時期によってあったりなかったりします。
- **外食：** MISO（和食の食べ放題）や Anari Sushi などがありますが、多くは中国系の経営で、日本の味とは違うこともあります。
- **持って行くと便利：** だしの素、カレールー、ふりかけなど軽くて日持ちするもの。
{% endcard %}

{% alert "⚠️ 日本からの持ち込みに注意", "warning" %}
EU には **EU 域外から肉製品・乳製品を持ち込めません**。肉エキス入りのレトルト食品やスープの素などは没収されることがあるので注意しましょう。
{% endalert %}

## 3. 携帯電話とインターネット

スペインに着いたら、携帯ショップで **プリペイド SIM（Prepago）** を契約するのが便利です。長期契約は不要です。

{% card "📱 主な通信会社と申し込み" %}
- **会社：** Orange、Vodafone、Movistar（ほかにも小さな会社があるので比較しましょう）。
- **必要書類：** 物理 SIM の申し込みには **パスポートの原本** が必要です。
- **料金の目安：** 月 **10〜15€** のプランで、データ通信と通話は十分なことが多いです。

{% alert "⚠️ 重要：カード決済の認証コード（OTP）", "warning" %}
母国のカードでネット決済すると、銀行から SMS で認証コードが届くことが多いですが、スペインの SIM に替えると受け取れなくなることがあります。

**対策：**

1. 出発前に、認証コードを **メールまたは銀行アプリ** で受け取れるよう銀行に設定してもらう。
2. カードを **Apple Pay / Google Pay** に登録すると、SMS 認証を省略できることがあります。
{% endalert %}

### 💸 更新とチャージ（有効期間：28日）

スペインのプリペイドは通常 **28日** 周期です。更新方法は2つ：

- **オンライン：** 期限前に通信会社から届く SMS のリンクから支払って更新できます。
- **店頭（現金のみ）：** ネットで払えない場合は、街中の **Tabacos（たばこ屋）** で電話番号と金額を伝えればチャージできます。**通常は現金のみです。**
{% endcard %}
