時刻表や料金は季節によって変わります。このページは2026年11月時点の情報です。出発前に必ず各社の公式サイトで確認してください。電車や LCC は **早く予約するほど安く**、直前だと何倍も高くなることがあります。
{% endalert %}

ムルシアには主な駅が2つあります。どちらを使うか確認しましょう：

- **鉄道駅：Murcia del Carmen**（Plaza de la Industria）。すべての列車がここに停まります。
- **バスターミナル：Estación de Autobuses de Murcia**（San Andrés、Calle Sierra de la Pila 3）。長距離バスと空港バスはここから出ます。

## 予約アプリの選び方

{% app "Trainline", "trainline", "https://www.thetrainline.com/" %}
**鉄道会社をまとめて比較できるアプリ。** スペインの高速鉄道は Renfe、OUIGO、iryo の3社があり、それぞれ別のサイトです。Trainline なら同じ日の便と料金を並べて比較し、そのまま購入できます。電子チケットはアプリに保存され、乗車時にスマホを見せるだけです。

- **留学生に便利な理由：** 英語で使え、**日本のクレジットカードも通りやすい** です（Renfe の公式サイトは海外カードを受け付けないことがあります）。
- **注意点：** 通常、少額の手数料がかかります（支払い前に表示）。便が決まったら各社の公式サイトと比べるのもおすすめです。
- **使い方：** 出発地（例：Madrid）と到着地（Murcia）、日付を入力 → 各社の便を比較 → 運賃を選ぶ → 支払い → 「マイチケット」に電子チケットが表示されます。
{% endapp %}

## 1. マドリード → ムルシア

{% card "🚄 高速鉄道（おすすめ）" %}
- **所要時間：** 最速約2時間45分、多くは3〜3.5時間。
- **運行会社：** Renfe（AVE など）、OUIGO、iryo。
- **マドリードの駅：** **Chamartín-Clara Campoamor** または **Atocha**。チケットで確認しましょう。
- **料金：** OUIGO は早めの予約で約9€から。直前だと50€を超えることもあります。
- **予約：** Renfe・OUIGO・iryo の公式サイトやアプリ、または Trainline・Omio で比較。
{% endcard %}

{% card "🚌 長距離バス（ALSA）" %}
- **所要時間：** 約5時間20分〜6時間30分。
- **乗り場：** マドリード空港の **T4 バスターミナル**（一部 T1）、または市内の Estación Sur。
- **料金：** 約37€から。
- **こんな人に：** マドリード空港に着いたばかりで荷物が多い人。乗り換えなしでムルシアのバスターミナルまで行けます。
{% endcard %}

## 2. バルセロナ → ムルシア

バルセロナはムルシアから遠く、**現在は直通列車がありません**。どの方法でも半日はかかります。

{% grid %}
{% card "✈️ 飛行機＋バス（最速）" %}
バルセロナから **アリカンテ（ALC）** まで約1時間10分。Vueling などが1日に何便も飛んでいます。その後、アリカンテ空港からバスでムルシアへ（第4章参照）。

Volotea はムルシア空港（RMU）にも飛んでいますが、便数は少なめです。
{% endcard %}
{% card "🚄 鉄道（乗り換え1回）" %}
最速約6.5時間、通常は7〜8時間以上。料金の変動が大きいので早めに予約しましょう。
{% endcard %}
{% card "🚌 長距離バス（ALSA）" %}
**Estació del Nord** バスターミナルから約10〜12時間。夜行バスなら1泊分の宿代を節約できます。
{% endcard %}
{% endgrid %}

## 3. バレンシア → ムルシア

- **バス（ALSA）：** バレンシアのバスターミナルから約4.5時間。最も安い方法です。
- **鉄道：** Estació del Nord から直通、またはアリカンテ乗り換えで約4.5〜5.5時間。
- **バレンシア空港から：** 地下鉄 **3号線か5号線** で Xàtiva 駅へ（Estació del Nord のすぐ隣）。高速鉄道の Joaquín Sorolla 駅へは、Àngel Guimerà で1号線か2号線に乗り換え、Jesús 駅で降ります。

## 4. ムルシア周辺の空港（海外旅行用）

{% card "🛫 アリカンテ空港 ALC（海外旅行に一番おすすめ）" %}
{% tag "約70km" %} {% tag "バスで約55分" %}

周辺で **最も路線が多い** 空港で、2026年夏は **30か国・141都市** に就航。Ryanair、Vueling、easyJet、Wizz Air、Volotea などの LCC が飛んでいます。ヨーロッパ旅行の多くはここからが便利です。

**行き方：**

- **ALSA の直通バス（一番簡単）：** ムルシアのバスターミナル ↔ アリカンテ空港、約55分、約8€、1日十数本。空港の乗り場はターミナル2階（出発階）の外、右側です。
- **バス＋鉄道：** 空港から **C6 バス**（3.85€、約20分間隔）でアリカンテ駅へ行き、列車で Murcia del Carmen へ（45分〜1時間ちょっと）。
{% endcard %}

{% card "🛫 ムルシア空港 RMU（Corvera）" %}
{% tag "約27km" %} {% tag "バス 1.85€", "price" %}

市内から一番近いですが路線は少なく、7か国・約20路線。**主にイギリス行き**（ロンドン、マンチェスターなど）で、ほかにダブリン、バルセロナ、カナリア諸島、フランス・イタリア・モロッコの一部路線があります。

**行き方：** ムルシアのバスターミナルから公共バスが出ています（片道1.85€、1日約10本）。タクシーも利用できます。季節で時刻が変わることがあるので事前に確認しましょう。
{% endcard %}

{% card "🛫 バレンシア空港 VLC" %}
{% tag "公共交通で約4〜5時間" %}

2026年夏は110路線と RMU より選択肢が多いですが、ムルシアからは遠いです。アリカンテから行きたい場所への便がないときや、バレンシア観光のついでに便利です。
{% endcard %}

{% card "🛫 マドリード空港 MAD（帰国・長距離便）" %}
アジアやアメリカなどへの長距離便は、たいていマドリード発です（またはアリカンテからヨーロッパの大都市へ飛んで乗り継ぎ）。ムルシアからは **ALSA の直通バスで T4 へ**、または高速鉄道でマドリードへ行き、地下鉄や近郊列車に乗り換えます。
{% endcard %}

## 5. 海外旅行の注意点

{% alert "⚠️ TIE がまだ手元にない場合は要注意", "warning" %}
TIE の手続き中にシェンゲン圏外（イギリスやモロッコなど）へ出ると、スペインに戻るときに問題が起きる可能性があります。旅行前に自分のビザと在留資格を確認し、不安があれば移民局や大学の国際課に相談しましょう。
{% endalert %}

- **シェンゲン圏内の旅行：** 入国審査はありませんが、**パスポート**（と TIE）は必ず持参しましょう。搭乗時に航空会社が身分証を確認します。
- **LCC の荷物ルールは厳しい：** 無料なのは小さなバッグ1つだけのことが多く、機内持ち込みスーツケースや預け荷物は追加料金です。直前に買うほど高くなり、サイズオーバーは搭乗口で料金を取られます。
- **Ryanair はオンラインチェックイン必須：** 空港カウンターでのチェックインは有料です。
- **比較ツール：** 航空券は Skyscanner や Google フライト、鉄道・バスは Trainline や Omio で比較し、各社の公式サイトで買うと安いことが多いです。

## 6. 日本への帰国

スペインから日本への直行便は限られており、ムルシア周辺からは乗り継ぎが基本です。マドリードのほか、ヨーロッパの大都市（パリ、フランクフルト、アムステルダムなど）や中東（ドーハ、ドバイ、イスタンブール）経由が一般的です。学期末は高くなるので早めに予約しましょう。
