## 1. 日本食を手に入れる

ムルシアに日本食専門のスーパーはほとんどありませんが、中国系のアジアスーパーで多くのものが手に入ります。

{% card "🏮 アジア系スーパー" %}
- **Hello Asia：** 中心部、Plaza Circular から徒歩約10分。
- **Happy Dulce（糖家福）：** 44番バスの路線沿い。
- **Wan Ka Le（萬家樂）：** 郊外、30番バス。品ぞろえが多め。

**見つかりやすいもの：** 醤油、米（短粒米・寿司用米）、豆腐、海苔、インスタント麺、冷凍餃子、緑茶など。味噌やだしなど日本の特定商品は店によってあったりなかったりします。
{% endcard %}

- **外食：** MISO（和食の食べ放題）、Anari Sushi などがあります。ただし多くは中国系の経営で、日本の味とは違うこともあります。
- **持って行くと便利なもの：** だしの素、カレールー、ふりかけなど軽くて日持ちするもの。ただし **EU には肉製品・乳製品を EU 域外から持ち込めない** ので、肉エキス入りの食品には注意しましょう。

## 2. 在留届と緊急連絡先

{% alert "📋 在留届を忘れずに", "info" %}
外国に **3か月以上** 滞在する日本人は、住所を管轄する在外公館に **在留届** を出す義務があります（オンラインの ORRnet から提出可）。災害や事件のときに大使館から連絡を受けられます。
{% endalert %}

{% card "🏛️ 在スペイン日本国大使館" %}
- 住所：Calle Serrano, 109, 28006 Madrid
- 電話：+34 91 590 7600
- バルセロナにも総領事館があります（Av. Diagonal, 640, Barcelona／電話 +34 93 280 3433）。

スペインの緊急番号：**112**（警察・救急・消防）
{% endcard %}

## 3. 日本との違い

- **生活時間：** 昼食は14〜16時ごろ、夕食は21時以降が普通です。日曜日はほとんどのスーパーが休みです。
- **時間の感覚：** バスや約束の時間はゆるめ。逆に、日本人の時間厳守は好印象です。
- **あいさつ：** 知り合い同士では頬を寄せる **2回のキス（dos besos）** が一般的ですが、学生同士では握手やハグでも大丈夫です。
- **キャッシュレス：** カード払いやタッチ決済がとても普及しています。
- **日本人は少数派：** ムルシアには日本人が少ないので、スペイン語や英語を使う機会が増え、語学の上達には好環境です。ESN のイベントなどに積極的に参加してみましょう。

## 4. 日本への帰国

スペインから日本への直行便は限られており、ムルシア周辺からは乗り継ぎが基本です。ヨーロッパの大都市（パリ、フランクフルト、アムステルダムなど）や中東（ドーハ、ドバイ、イスタンブール）経由が一般的です。空港の情報は[長距離移動](travel.html)をご覧ください。
