{% alert "📌 はじめに", "info" %}
このページは UCAM 国際課（ORI）の交換留学生向け資料（2026年11月）をもとにまとめています。規定は毎年変わることがあるので、必ず UCAM の最新の案内に従ってください。授業に関する質問は、一般窓口ではなく **UCAM の交換留学コーディネーター（tutor）** に問い合わせましょう。
{% endalert %}

## 1. 全体の流れ

{% card %}
1. **オンライン事前登録：** UCAM のシステムでアカウントを作成します。所属大学のメールではなく **Gmail などの個人メール** を使いましょう。登録後、内部コードが届きます。
2. **交換留学の申請フォーム：** そのコードでログインし、写真、パスポート、成績証明書、語学証明、保険、**Learning Agreement の案** をアップロードします。送信後「Your application has been submitted successfully」と表示されるのを確認し、スクリーンショットを保存しましょう。
3. **審査を待つ：** 締め切り後、登録が承認されると、**正式な Learning Agreement をオンラインで完成させる** 方法がメールで届きます。UCAM が署名するのはこの段階です。
4. **到着後の履修変更：** 学期の初めに **add/drop week** があり、授業を変更できます。
{% endcard %}

{% alert "📅 申請締め切り" %}
前期は **5月10日ごろ**、後期は **11月1日ごろ**。実際の日程は UCAM と所属大学の案内に従ってください。所属大学の学内締め切りはもっと早いことが多いです。
{% endalert %}

## 2. Learning Agreement のダウンロード

すべての書類は UCAM 公式サイトの **[Incoming Students ページ](https://www.ucam.edu/servicios/oficina-relaciones-internacionales/incoming-students)** にあります。

{% card "📄 プログラム別の書類" %}
申請時にプログラムを選びます。ヨーロッパの大学は **Erasmus+**、中南米は **UCAM Ibero**、アメリカ・カナダ・**アジア（日本を含む）は UCAM USA/Overseas** です。

- **Overseas／北米プログラム用：** [learning_agreement_completo.docx](https://www.ucam.edu/sites/default/files/public/Oficina-relaciones-internacionales/Incoming-Students/Overseas-Program/learning_agreement_completo.docx)
- **Erasmus 用：** [learning_agreement.docx](https://www.ucam.edu/sites/default/files/public/Oficina-relaciones-internacionales/programa-erasmus-estudio/learning_agreement.docx)
- **記入方法（英語 PDF）：** [Elaborate your learning agreement](https://www.ucam.edu/sites/default/files/public/Oficina-relaciones-internacionales/Incoming-Students/Erasmus-Students-Exchange-at-UCAM/elaborate-your-learning-agreement.pdf)
- **手続きの全体説明：** [Procedure（英語）](https://docs.google.com/document/d/e/2PACX-1vSOlUS-XcGsCoa5Om71TYvhzSLXx8kaSfjsMwjPrSoufTyRz3Jy7nhW5QDePWw1qg/pub)

どれを使うかわからない場合は、所属大学の国際課か UCAM に問い合わせましょう。
{% endcard %}

{% alert "⚠️ 注意", "warning" %}
- 申請時にアップロードする Learning Agreement は **あくまで案** です。この時点で UCAM の先生や国際課に署名を依頼する必要はありません。
- UCAM は **OLA（Online Learning Agreement）を使用していません**。
- 先に **所属大学の担当教員** と、どの授業が単位認定されるか確認しましょう。
{% endalert %}

## 3. 履修のルール

- **留学する学期に開講される授業のみ：** 前期は9月〜1月、後期は1月末〜6月。
- **単位：** 1学期あたり最大約30 ECTS。多くの授業は6 ECTS、2週間の集中講義は2 ECTS。
- **ECTS の50〜60%以上を UCAM の同じ学部から** 取る必要があります（主担当の指導教員を割り当てるため）。
- **学部の授業のみ**：修士課程の授業は交換留学生には開放されていません。
- **英語で授業がある学部：** 経営学（BBA）、心理学、スポーツ科学、国際関係、歯学、獣医学。教育学、翻訳・通訳にも英語で受けやすい授業があります。そのほかの学部は主に **スペイン語** です。
- **人気学部は定員あり**（1授業あたり交換留学生約5名）：翻訳・通訳、BBA、マーケティング、教育、心理学、スポーツ科学。成績・専攻との関連・英語力で決まるので、**早めに申請** しましょう。
- **卒業研究（TFG）は評価されません：** Learning Agreement に載せることはできますが、成績証明書には「Not attended」と記載され、成績も単位もつきません。
- **スペイン語講座**（有料）も Learning Agreement に記入し、コード欄は空欄にします。問い合わせ：escueladeidiomas@ucam.edu

{% card "🧪 特別なルールがある学部" %}
- **医学：** 所属大学で医学を専攻している学生のみ。1授業あたり最大4名、病院での実習は不可。
- **心理学：** 1授業・1言語あたり最大4名、健康科学系の学生が優先。実習、卒業論文、3・4年の選択科目は不可。
- **看護・理学療法・作業療法の実習：** 到着前に UCAM のコーディネーターにメールで枠を確認しましょう。看護には別の締め切りがあり、カルタヘナキャンパスに配属されることもあります。
- **語学力：** スペイン語は B1 推奨（健康科学の実習前は必須）、英語授業は B2 推奨。
{% endcard %}

## 4. 授業情報の調べ方

{% card "🔎 授業と授業コードを探す" %}
1. UCAM の [学部課程カタログ](https://www.ucam.edu/estudios?f=Grado) を開く
2. **Modalidad：Presencial（対面）**、**Sede：Murcia** で絞り込む
3. 学部のページを開き、**カリキュラム（Plan de estudios）** から授業を探す
4. 授業のページで **授業コード** と説明を確認する。Learning Agreement の授業名はそのページの表記どおり（できればスペイン語、必要なら英語も併記）に書く
5. 国際課がまとめた [授業一覧（Excel）](https://www.ucam.edu/sites/default/files/public/Oficina-relaciones-internacionales/Incoming-Students/Erasmus-Students-Exchange-at-UCAM/listado_asignaturas-plan.xlsx) もダウンロードできます

学部名は略称でも構いません（例：ADE/BBA 経営学、CAFD/SC スポーツ科学、TI 翻訳、PSI/PSY 心理学）。
{% endcard %}

## 5. 到着後：時間割・教室・オンライン学習

{% card "🗓️ 時間割と教室" %}
- **時間割：** 各学部のページに学年・学期別の **「Horarios y exámenes」（時間割と試験日程）** の PDF があります。授業の時間と **教室コード**（例：`P8_1_A02`）が載っています。
- **キャンパスマップ：** 教室はいくつもの建物に分かれています。UCAM の [Google キャンパスマップ](https://www.google.com/maps/d/viewer?hl=es&mid=1wfxoEnVk48CVOkJI8_otHKZVCNlWWvgu&ll=37.99122541130507%2C-1.1850123096888865&z=19) で場所を確認し、最初の授業は早めに出かけましょう。
- **学年暦：** [2026-2027 学年暦（英語 PDF）](https://international.ucam.edu/sites/ucam.edu.en/files/documentos/calendario-academico-murcia-ingles.pdf)。授業開始日、休暇、試験期間が載っています。歯学・心理学・看護・医学は日程が異なる場合があるので別途確認を。
{% endcard %}

{% card "💻 Campus Virtual（オンライン学習）" %}
UCAM のアカウントができたら、教材、課題、お知らせ、試験、カレンダーはすべて **[Campus Virtual](https://cv.ucam.edu/)** にあります。大学メールは [correo.ucam.edu](http://correo.ucam.edu/)、ログインなどの問題は [UCAM の IT サポート](https://soporte.ucam.edu/) へ。
{% endcard %}
