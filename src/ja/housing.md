## 1. 物件の探し方

知人の紹介以外では、スペインで最もよく使われているのが **idealista** アプリです。

{% app "idealista", "idealista", "https://www.idealista.com/" %}
- **言語：** 英語や中国語に設定できるので、言葉の心配はいりません。
- **検索方法：** 地図検索、範囲を描いて検索、電話番号での連絡に対応しています。
- **部屋のタイプ：** 交換留学生の多くはシェアハウスの **個室（Habitación）** を探します。
{% endapp %}

## 2. スペインのシェアハウスはこんな感じ

{% card "🏡 日本の一人暮らしとの違い" %}
- **キッチンは共用：** ほぼ必ずあり、コンロ・オーブン・電子レンジ・調理器具もそろっています。**冷蔵庫は一人一段** などと分けて使うのが普通です。
- **お風呂はシャワーだけ：** 浴槽がない物件が多く、バスルームは数人で共用です。
- **洗濯機はあるが乾燥機は少ない：** 洗濯物はベランダや物干しで乾かします。ムルシアの日差しならすぐ乾きます。
- **光熱費（gastos）：** 水道・電気・ガス・Wi-Fi が家賃に **含まれているか** 必ず確認しましょう。含まれていなければ同居人で割り勘です。
- **敷金（fianza）：** 通常 **家賃1か月分**。退去時に問題がなければ返金されます。礼金のような習慣はありません。
- **暑さと寒さ：** 夏は35度を超える日も多く、冬は **暖房のない部屋** が多いので室内が寒く感じます。エアコン（aire acondicionado）の有無を確認しましょう。
{% endcard %}

## 3. 連絡と契約のアドバイス

{% app "WhatsApp", "whatsapp", "https://www.whatsapp.com/" %}
スペインでは大家さんもルームメイトもクラスのグループも、ほぼ全員 WhatsApp です。出発前にインストールしておきましょう。
{% endapp %}

- **WhatsApp を使う：** メッセージはスペイン語で書くのがおすすめです。1日返事がなければ、丁寧に催促しましょう。
- **契約条件：** 性別の指定（女性のみなど）がないか確認しましょう。多くの大家は1年以上の長期契約を好みます。
- **必ず内見する：** 写真と実物の違いを避けるため、決める前に必ず自分の目で見ましょう。
- **支払い方法：** 現金か振込かを確認しましょう。振込には通常スペインの銀行口座が必要です。

## 4. スペインの賃貸豆知識（文化の違い）

{% alert %}
- **鍵：** シェアハウスの個室のドアには **鍵がない** ことがよくあります。プライバシーが気になる場合は事前に確認しましょう。
- **階数の数え方：** 階は **Bajo（地上階）→ 1 → 2…** と数えます。日本の1階が Bajo なので、スペインの「1階」は **日本の2階** にあたります。
- **家の中でも靴：** スペインでは室内でも靴のままが一般的です。脱ぎたい人はスリッパを用意しましょう。
- **キッチンは重要：** スペインの外食は高いので、キッチン付きの物件を選びましょう。ほとんどの物件に設備があります。
{% endalert %}

## 5. おすすめのエリア

中心部（Centro）以外で物件が多いエリア：

- **人気エリア：** Guadalupe、La Ñora、Senda de Granada、Espinardo。
- **個人的なおすすめ：** 生活の便利さと人付き合いを考えると中心部（Centro）が一番です。
- **代わりの選択肢：** 予算が厳しい場合や中心部で見つからない場合は Guadalupe や La Ñora（郊外）。
