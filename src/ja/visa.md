## ステップ1：予約（Cita Previa）を取る

{% card %}
予約は公式サイトから行います：[外国人手続き予約ポータル](https://sede.administracionespublicas.gob.es/pagina/index/directorio/icpplus)

**手順：**

1. 県（provincia）で **Murcia** を選ぶ。
2. 手続きで **POLICIA-TOMA DE HUELLAS**（指紋採取）を選ぶ。
3. 個人情報を入力し、空いている事務所を選ぶ。

{% alert "💡 アドバイス：" %}
TIE の予約枠は不定期に出て、非常に取りにくいです。毎朝8時〜10時ごろにサイトを確認しましょう。渡航前から試す場合は、スペインのサーバーに接続した VPN を使うとよいこともあります。
{% endalert %}
{% endcard %}

## ステップ2：必要書類

{% card %}
- **EX-17 申請書**：記入・署名済み（原本＋コピー1部）。
- **有効なパスポート**：原本と全ページのコピー（空白ページ・入国スタンプのページを含む）。
- **受入許可書**：UCAM が発行する正式な入学許可書類。
- **住民登録証明（Empadronamiento）**：ムルシア市役所で取得。<br><small>窓口：Calle Dr. Alonso de Espejo, 7, 30007 Murcia</small>
- **手数料 790-012**：銀行で支払った証明（約16ユーロ）。
{% endcard %}
