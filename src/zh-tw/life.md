## 1. 外食選擇 (Eating Out)

西班牙餐廳動輒 15-20€，留學生平時多以速食、Kebab 或超市微波食品為主。

{% card "🍔 速食系列 <small>(均消約 8-10€)</small>" %}
- **Plaza Circular 周邊：** {% pin "Plaza Circular, Murcia" %} 有 Popeyes、KFC、Burger King。注意：此處 BK 位於英國宮附近，青少年多且服務普通。
- **Senda de Granada 區：** {% pin "Senda de Granada, Murcia" %} BK 位於家樂福旁，環境較市中心舒適。
- **McDonald's：** 需往購物中心方向（Churra 站）。**強烈建議下載 App** 換取優惠券，但注意這裡飲料不可續杯。
- **其他：** IKEA（Príncipe Felipe 站）與 Taco Bell 也是相對便宜的選擇。

### 🌯 Kebab（土耳其烤肉） <small>(10€ 以下首選)</small>

路邊隨處可見，推薦 **Hakan、Musa、Mundo Kebab**。套餐通常包含主食（Pita/Box 等）、薯條與飲料，份量足且不踩雷。

### 🍕 中價位與慶祝推薦 <small>(均消 12-20€+)</small>

- **披薩／義大利麵：** La Pierotti Pizzeria、Mano a mano。
- **聚餐首選：** Anari Sushi（吃到飽）、MISO（日料吃到飽）、大龍焱火鍋。
{% endcard %}

## 2. 超市與自煮 (Grocery Shopping)

{% alert "⚠️ 重要提醒：" %}
除了家樂福（Carrefour），當地超市（Mercadona、Lidl 等）在**星期日與國定假日**一律不營業！請務必提前囤貨。
{% endalert %}

{% card "🛒 當地超市" %}
Mercadona、Día、Consum、Lidl、El Corte Inglés。基本生活所需的油鹽米醬、馬鈴薯、高麗菜等皆與台灣相似，生活無虞。

### 🏮 亞洲超市 (Oriental Supermarket)

若想念青江菜、白蘿蔔、烏醋或沙茶醬，需前往亞超：

- **Hello Asia：** 位於市中心，離 Plaza Circular 步行 10 分鐘。
- **糖家福（Happy Dulce）：** {% pin "Happy Dulce Murcia" %} 位於 44 號公車路線上，抵達難度適中。
- **萬家樂（Wan Ka Le）：** {% pin "Wan Ka Le Murcia" %} 位於郊區，需搭乘 30 號公車。

{% map "Hello Asia, Murcia", "Hello Asia — 在 Google 地圖開啟" %}

亞超大多是華人經營，店員通常會說中文，結帳、找東西都可以直接用中文問。
{% endcard %}

{% card "🛒 亞超常見、台灣人會想買的東西" %}
實際庫存每家不同、也會變動，以下是常見類別：

- **醬料：** 沙茶醬、烏醋、醬油、醬油膏、豆瓣醬、麻油
- **蔬菜：** 青江菜、白蘿蔔、大白菜、韭菜、豆芽
- **主食：** 米粉、冬粉、各種麵條、糯米、泰國米
- **冷凍食品：** 水餃、包子、湯圓、魚丸
- **其他：** 豆腐、泡麵、茶葉、零食

想找特定的台灣品牌，可以拍包裝照片給店員看。<small>這份清單歡迎曾在穆爾西亞生活的同學補充。</small>
{% endcard %}

{% alert "⚠️ 從台灣帶東西要注意", "warning" %}
歐盟**禁止旅客從歐盟以外帶入肉類和乳製品**，包括肉鬆、肉乾、香腸，以及**含肉的泡麵調理包**。被查到會被沒收甚至罰款。醬料、茶葉、乾貨等一般比較沒問題。
{% endalert %}

## 3. 網路通訊 (Mobile & Internet)

抵達西班牙後，可直接前往門市辦理 **SIM 卡（Prepago）**。以下是西班牙最大的三家電信商：

{% card "📱 主要電信商與申辦" %}
- **公司：** Orange、Vodafone、Movistar（還有其他小公司，可以自行比較）。
- **必備文件：** 辦理時請務必攜帶**護照正本**，可以直接申辦實體 SIM 卡。
- **預計資費：** 通常一個月約 **10-15€** 的套餐流量便非常充足。

{% alert "⚠️ 重要：關於刷卡驗證 (OTP)", "warning" %}
使用台灣信用卡線上購物或加值時，通常需要手機簡訊驗證碼。若換成西班牙 SIM 卡將無法接收簡訊。

**解決方案：**

1. 出國前先向銀行設定改用 **Email 接收驗證碼**。
2. 綁定 **Apple Pay / Google Pay**，可跳過簡訊驗證。
{% endalert %}

### 💸 續約與加值方式 (Validity: 28 Days)

西班牙預付卡通常以 **28 天**為一週期，加值方式有二：

- **線上加值：** 到期前電信商會寄送簡訊，點擊簡訊內的連結即可線上刷卡續約。
- **實體店加值（僅限現金）：** 若無法刷卡，可直接前往路邊的 **Tabacos（菸草店）**，告知店員你的門號與金額即可充值。
{% endcard %}
