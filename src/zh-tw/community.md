## 1. 想念台灣味：亞洲超市與能買到的東西

穆爾西亞的亞洲超市大多是華人經營，店員通常會說中文，結帳、問東西都可以直接用中文。

{% card "🏮 亞洲超市" %}
- **Hello Asia：** 市中心，離 Plaza Circular 步行約 10 分鐘，最方便。
- **糖家福（Happy Dulce）：** 44 號公車路線上，去學校順路。
- **萬家樂（Wan Ka Le）：** 郊區，需搭 30 號公車，東西比較齊全。
{% endcard %}

{% card "🛒 亞超常見、台灣人會想買的東西" %}
實際庫存每家不同、也會變動，以下是常見類別：

- **醬料：** 沙茶醬、烏醋、醬油、醬油膏、豆瓣醬、麻油
- **蔬菜：** 青江菜、白蘿蔔、大白菜、韭菜、豆芽
- **主食：** 米粉、冬粉、各種麵條、糯米、泰國米
- **冷凍食品：** 水餃、包子、湯圓、魚丸
- **其他：** 豆腐、泡麵、茶葉、零食

想找特定的台灣品牌，可以直接問店員，或拍包裝照片給店員看。

<small>這份清單歡迎曾在穆爾西亞生活的同學補充。</small>
{% endcard %}

{% alert "⚠️ 從台灣帶東西要注意", "warning" %}
歐盟**禁止旅客從歐盟以外帶入肉類和乳製品**，包括肉鬆、肉乾、香腸，以及**含肉的泡麵調理包**。被查到會被沒收甚至罰款。醬料、茶葉、乾貨等一般比較沒問題。
{% endalert %}

## 2. 與華人社群相處

在穆爾西亞你會遇到兩種華人：

- **在地經營商店的華人：** 西班牙有不少華人經營的超市、雜貨店（bazar）、餐廳和美甲店，許多來自中國浙江。他們通常對說中文的客人很親切，有時也能幫忙解決生活上的問題。
- **來自中國大陸的同學：** UCAM 和穆爾西亞大學都有中國留學生或交換生，有些課也可能同班。

{% card "💬 溝通小技巧" %}
- **用詞差異：** 有些詞不太一樣，例如「視頻／影片」、「質量／品質」、「信息／訊息」、「打車／叫車」、「U盤／隨身碟」。聽不懂就直接問，大家通常都很樂意解釋。
- **聯絡方式：** 中國同學多用 **微信（WeChat）**，西班牙當地則幾乎都用 **WhatsApp**。如果想加入華人社群的群組，可以下載微信。
- **實用資訊群組：** 華人社群常在群組裡分享二手家具、租屋、搬家、團購等資訊，加入後會方便很多。
- **政治話題：** 對兩岸議題每個人觀點不同，保持尊重即可，不必勉強討論。從課業、旅遊、美食這些共同的留學生活聊起，最容易交到朋友。
{% endcard %}

## 3. 簽證、健保與保險

- **短期旅遊：** 持台灣護照到申根區免簽 90 天，但**交換超過 90 天要事先在台灣申請學生簽證**，抵達後再辦 TIE（見[簽證與居留證](visa.html)）。
- **健保自墊醫療費用核退：** 在國外看病先自費，回台後可申請健保核退。要在**看診或出院後 6 個月內**申請，準備收據、診斷證明等文件。核退有每季公告的上限，可能遠低於你在西班牙實際付的醫療費。
- **一定要另外買保險：** 申請學生簽證本來就需要涵蓋整段停留的私人醫療保險，也比只靠健保核退安心。

## 4. 回台灣的機票

西班牙沒有直飛台灣的航班，回台通常要轉機一次：

- **中東轉機：** 土耳其航空（伊斯坦堡）、阿聯酋航空（杜拜）、卡達航空（杜哈）等，馬德里、巴塞隆納都有航班。
- **歐洲轉機：** 華航、長榮在多個歐洲城市有直飛台北的航班（例如阿姆斯特丹、維也納、巴黎、倫敦、法蘭克福等，實際航點請查詢），可以先從阿利坎特或馬德里飛到這些城市再轉機。
- 機票比價可以用 Skyscanner 或 Google Flights。更多機場資訊請看[長途交通](travel.html)。
