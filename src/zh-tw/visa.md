## 出發前：在台灣申請學生簽證

持台灣護照到西班牙觀光免簽 90 天，但**交換超過 90 天就要在出發前申請學生簽證**。簽證向**西班牙駐台北的辦事處**申請（聯絡信箱 ofc.taipei@maec.es），以下是學長姐分享的經驗，實際規定請以辦事處最新公告為準。

{% card "📄 常見要準備的文件" %}
- 申請表兩份（英文或西文填寫並親簽）、近六個月白底彩色照片兩張
- 護照正本與影本、身分證影本
- UCAM 入學許可（載明學校、課程與期間）、交換生資格英文證明
- **海外醫療保險英文證明**（要涵蓋整段停留）
- **財力證明**：近三個月的英文存款證明與交易明細，金額大約是**每月 600 歐元 × 停留月數**；可由自己或家長擔保
- 停留較長時（例如超過 135 天）還可能要 **英文良民證** 和 **英文健康檢查證明**（需在六個月內開立）
{% endcard %}

{% alert "⏰ 時間抓寬一點", "warning" %}
建議出發前**兩個月**左右送件，審核可能要一個月。良民證、健康檢查都要時間，最好收到 UCAM 入學許可後就開始準備。
{% endalert %}

## 抵達後第一步：預約 Cita Previa

{% card %}
1. 前往政府網站：[https://mptmd.sede.gob.es/](https://mptmd.sede.gob.es/)
2. 往下捲到 **Procedimientos**，點選 **Extranjería**
3. 點選 **Cita Previa de Extranjería**
4. 拉至最下方點選 **Acceder al procedimiento**
5. 選擇 **Murcia** 地區，並選擇 **POLICIA-TOMA DE HUELLAS**（按指紋）

{% alert %}
※ 居留證預約非常難搶，建議每天早上 8-10 點刷網頁，甚至在去之前就開始連 VPN 到當地伺服器刷。注意西班牙比台灣慢 6～7 小時，西班牙早上 8 點是台灣下午 2～3 點。
{% endalert %}
{% endcard %}

## 第二步：準備文件

{% card %}
- **EX-17 表格**：正本與影本。
- **護照**：全本影本（包含空白頁與入境章頁）。
- **入學確認書**：UCAM 發放的錄取信。
- **住址證明（Empadronamiento）**：需去市政機關辦理。<br><small>地址：Calle Dr. Alonso de Espejo, 7, 30007 Murcia, Spain</small>
- **規費單 790-012**：需去銀行繳費，目前約 16 歐元。

## 健保與保險

- **健保自墊醫療費用核退：** 在西班牙看病先自費，回台後可申請健保核退，要在**看診或出院後 6 個月內**申請，準備收據、診斷證明等文件。核退有每季公告的上限，可能遠低於你在西班牙實際付的醫療費。
- **一定要另外買海外醫療保險：** 簽證本來就要求，也比只靠健保核退安心。
- 出國期間健保要不要停保，會影響回台後的權益，出發前可先查詢健保署的規定。
