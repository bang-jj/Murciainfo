## 1. 尋找房源管道

除了認識的人介紹外，當地最常用的就是 **idealista** 應用程式。

{% app "idealista", "idealista", "https://www.idealista.com/" %}
- **語言設定：** 可設定中文或英文，不必擔心語言隔閡。
- **多元搜尋：** 支援地圖搜尋、畫圈範圍搜尋、或按電話搜尋。
- **房型選擇：** 留學生通常選擇「居室（Habitación）」合租較多。
{% endapp %}

另外，**華人社群的微信群組**也常有人轉租房間或找室友，透過亞超或認識的華人同學問問看，有時能找到用中文就能溝通的房東。

## 2. 和台灣租屋不一樣的地方

台灣常見的「套房」在西班牙學生之間很少見，大部分人住的是**整層公寓分租**，比較像台灣的「雅房」：

{% card "🏡 西班牙合租公寓長這樣" %}
- **公共廚房：** 幾乎一定有，而且是大家**共用**的。爐子、烤箱、微波爐、鍋碗瓢盆通常都有，**冰箱多半是一人分一層或一格**，櫥櫃也會分好。台灣租屋常見「不能開伙」，在西班牙反而是天天自己煮。
- **共用衛浴：** 大多是幾個人共用一間浴室，有獨立衛浴的房間比較少也比較貴。
- **客廳與洗衣機：** 通常有共用客廳和洗衣機，但**很少有烘衣機**，衣服大多晾在陽台或曬衣架上。
- **室友：** 可能來自世界各地，也可能是西班牙學生，是練西文的好機會。可以先和室友講好打掃輪值。
{% endcard %}

{% alert "💶 錢的部分要問清楚" %}
- **押金（Fianza）：** 通常是**一個月房租**，簽約時給，退租時檢查沒問題才退還。
- **水電網（Gastos）：** 房租有沒有包含水、電、瓦斯、網路，一定要先問。沒包含的話通常是室友平分帳單。
- **冷氣與暖氣：** 穆爾西亞**夏天非常熱**（常超過 35 度），冬天室內卻可能比台灣冷，因為很多房子**沒有暖氣**、保暖差。看房時記得問有沒有冷氣（aire acondicionado）。
{% endalert %}

## 3. 聯絡與簽約建議

{% app "WhatsApp", "whatsapp", "https://www.whatsapp.com/" %}
西班牙人聯絡幾乎都用 WhatsApp，房東、室友、同學群組都在這裡，出發前先下載好。
{% endapp %}

- **優先使用 WhatsApp：** 建議以「西文」撰寫訊息。若房東一天未回覆，請記得禮貌性地催促訊息。台灣常用的 LINE 在西班牙幾乎沒人用。
- **注意租期條件：** 留意是否有性別限制，且多數房東偏好一年以上的長租。
- **現場看房：** 務必親自看房後再決定，避免網路照片與現實的資訊落差。
- **付款方式：** 詢問是否接受現金或需要轉帳。若需轉帳，則必須在當地銀行開戶。

## 4. 西班牙租房小常識（文化差異）

{% alert %}
- **門鎖問題：** 西班牙分租套房的「臥室門」通常是**沒有鎖**的，若在意隱私請務必提前詢問。
- **樓層計算：** 樓層順序為 **Bajo（地面層，B）→ 1 → 2…**。台灣的 1 樓在西班牙叫 Bajo，所以當地的「1 樓」等於台灣的 2 樓。
- **進門不脫鞋：** 西班牙人在家通常不脫鞋。如果你習慣脫鞋，可以自己準備室內拖鞋。
{% endalert %}

## 5. 區域建議

除了市中心（Centro）之外，房源較多的地區包括：

- **熱門區域：** Guadalupe、La Ñora、Senda de Granada、Espinardo。
- **個人建議：** 首選市中心（Centro），生活機能與社交便利性最佳，也離 Hello Asia 等亞洲超市近。
- **備選區域：** 若預算考量或市區無房，可考慮 Guadalupe 與 La Ñora（屬偏遠地區）。
