穆爾西亞有兩個主要的交通站，搭車前先確認是哪一個：

- **火車站：Murcia del Carmen**（Plaza de la Industria），所有火車都停這裡。
- **巴士總站：Estación de Autobuses de Murcia**（又稱 San Andrés，Calle Sierra de la Pila 3），長途巴士與機場巴士都在這裡。

## 訂票 App 怎麼選

{% app "Trainline", "trainline", "https://www.thetrainline.com/" %}
**一個 App 比較所有火車公司**。西班牙高鐵有 Renfe、OUIGO、iryo 三家，各自有官網，Trainline 可以把同一天的班次和票價放在一起比，直接買票，電子票存在 App 裡，上車出示手機即可。

- **適合台灣同學的原因：** 介面有英文，**台灣信用卡通常可以順利付款**（Renfe 官網有時不接受外國卡或卡在驗證）。
- **缺點：** 通常會收一點手續費，結帳時會顯示金額。確定班次後，也可以再到該公司官網比較價格。
- **怎麼用：** 輸入出發地（例如 Madrid）和目的地（Murcia）、日期 → 比較各家班次 → 選票種 → 付款 → 電子票出現在「我的車票」。

## 1. 從馬德里到穆爾西亞

從台灣飛來，多半會在 **馬德里機場（MAD）** 降落，再轉高鐵或巴士到穆爾西亞。拖著大行李的話，在機場直接搭 ALSA 巴士最省事。

{% card "🚄 高鐵（最推薦）" %}
- **車程：** 最快約 2 小時 45 分，多數班次約 3～3.5 小時。
- **營運公司：** Renfe（AVE 等）、OUIGO、iryo 等都有班次。
- **馬德里上車站：** **Chamartín-Clara Campoamor** 或 **Atocha**，買票時看清楚是哪一站。
- **票價：** OUIGO 提早買最低約 9€ 起，臨時買可能 50€ 以上。
- **買票：** Renfe、OUIGO、iryo 官網或 App，也可用 Trainline、Omio 比價。
{% endcard %}

{% card "🚌 長途巴士（ALSA）" %}
- **車程：** 約 5 小時 20 分～6 小時半。
- **上車地點：** 馬德里機場 **T4 巴士站**（部分班次在 T1），或市區的 Estación Sur。
- **票價：** 約 37€ 起。
- **適合：** 剛降落馬德里機場、行李多、不想轉車的人，可以在機場直接上車到穆爾西亞巴士總站。
{% endcard %}

## 2. 從巴塞隆納到穆爾西亞

巴塞隆納離穆爾西亞比較遠，**目前沒有直達火車**，各方式都要花上半天。

{% grid %}
{% card "✈️ 飛機＋巴士（最快）" %}
從巴塞隆納機場飛 **阿利坎特（ALC）** 約 1 小時 10 分，Vueling 等航空每天多班。再從阿利坎特機場搭巴士到穆爾西亞（見下方第 4 節）。

Volotea 也有飛穆爾西亞機場（RMU）的航班，但班次較少。
{% endcard %}
{% card "🚄 火車（需轉車一次）" %}
最快約 6 小時半，一般 7～8 小時以上。票價波動大，提早買比較划算。
{% endcard %}
{% card "🚌 長途巴士（ALSA）" %}
從 **Estació del Nord** 巴士站出發，約 10～12 小時，有夜車可以省一晚住宿。
{% endcard %}
{% endgrid %}

## 3. 從瓦倫西亞到穆爾西亞

- **巴士（ALSA）：** 從瓦倫西亞巴士總站出發，約 4.5 小時，最便宜。
- **火車：** 從 Estació del Nord 出發，有直達或在阿利坎特轉車，約 4.5～5.5 小時。
- **從瓦倫西亞機場：** 先搭地鐵 **3 號或 5 號線**進市區，到 Xàtiva 站（旁邊就是 Estació del Nord 火車站）；要去高鐵站 Joaquín Sorolla 則在 Àngel Guimerà 轉 1 或 2 號線到 Jesús 站。

## 4. 穆爾西亞附近的機場（出國用）

{% card "🛫 阿利坎特機場 ALC（最推薦出國）" %}
{% tag "距離約 70 公里" %} {% tag "巴士約 55 分鐘" %}

附近**航線最多**的機場，2026 年夏季有 **141 個航點、30 個國家**，Ryanair、Vueling、easyJet、Wizz Air、Volotea 等廉航都有飛。想去歐洲其他國家旅遊，大多從這裡出發最方便。

**怎麼去：**

- **ALSA 巴士直達（最方便）：** 穆爾西亞巴士總站 ↔ 阿利坎特機場，約 55 分鐘，約 8€，一天十多班。機場的搭車處在航廈 2 樓（出境樓層）外面的右側。
- **巴士＋火車：** 從機場搭 **C6 公車**（3.85€，約每 20 分鐘一班）到阿利坎特火車站，再搭火車到 Murcia del Carmen（45 分鐘～1 小時多）。
{% endcard %}

{% card "🛫 穆爾西亞機場 RMU（Corvera）" %}
{% tag "距離約 27 公里" %} {% tag "公車 1.85€", "price" %}

離市區最近，但航線不多，約 20 條航線、7 個國家，**以英國為主**（倫敦、曼徹斯特等），另有都柏林、巴塞隆納、加那利群島，以及部分法國、義大利、摩洛哥航線。

**怎麼去：** 穆爾西亞巴士總站有公車到機場，單程 1.85€，一天約 10 班；或搭計程車。班次可能隨季節調整，出發前先確認。
{% endcard %}

{% card "🛫 瓦倫西亞機場 VLC" %}
{% tag "大眾運輸約 4～5 小時" %}

2026 年夏季有 110 條航線，比 RMU 選擇多，但離穆爾西亞較遠。適合阿利坎特沒有想去的航點，或是剛好要順便去瓦倫西亞玩的時候。
{% endcard %}

{% card "🛫 馬德里機場 MAD（回國／洲際航班）" %}
回台灣或飛亞洲、美洲等長程航線，通常會從馬德里出發（或在阿利坎特搭機到歐洲大城市轉機）。從穆爾西亞到馬德里機場，可搭 **ALSA 巴士直達 T4**，或搭高鐵到馬德里再轉地鐵／通勤火車。
{% endcard %}

## 5. 出國旅遊小提醒

{% alert "⚠️ 居留證還沒拿到前出國要注意", "warning" %}
如果 TIE 還在辦理中，離開申根區（例如去英國、摩洛哥）後可能無法順利回到西班牙。出國前請先確認自己的簽證與居留狀態，必要時向移民局或學校國際處詢問。
{% endalert %}

- **申根區內旅行：** 西班牙飛法國、義大利等申根國家不用過海關，但還是要帶**護照**（和 TIE），航空公司登機時會檢查。
- **廉航行李規定很嚴：** 免費的通常只有一個小包，登機箱和托運行李都要另外加購，且越晚買越貴。尺寸超過會在登機口被收費。
- **Ryanair 要提前線上報到：** 沒有線上報到、到機場櫃檯辦理會被收費。
- **比價工具：** 機票用 Skyscanner、Google Flights；火車、巴士用 Trainline、Omio 比價後，再到官網買通常比較便宜。

## 6. 回台灣的機票

西班牙沒有直飛台灣的航班，回台通常要轉機一次：

- **中東轉機：** 土耳其航空（伊斯坦堡）、阿聯酋航空（杜拜）、卡達航空（杜哈）等，馬德里、巴塞隆納都有航班。
- **歐洲轉機：** 華航、長榮在幾個歐洲城市有直飛台北的航班（實際航點請查詢），可以先從阿利坎特或馬德里飛到這些城市再轉機。
- 用 Skyscanner 或 Google Flights 比價，學期結束前後機票較貴，建議提早訂。
