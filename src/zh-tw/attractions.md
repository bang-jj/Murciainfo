## 1. 市中心與市郊（輕軌／公車可達）

{% grid %}
{% figure "../images/places/cathedral.jpg", "穆爾西亞主教座堂" %}
{% figure "../images/places/real-casino.jpg", "皇家賭場（Real Casino）內部" %}
{% endgrid %}

{% card "🏛️ 文化與地標" %}
- **穆爾西亞主教座堂（Catedral de Murcia）：** {% pin "Catedral de Murcia" %} {% tag "門開時可自由進出，導覽與登上鐘塔需門票", "price" %} 城市象徵。教堂與鐘塔的導覽是分開賣的，但要注意導覽只有**全西班牙文**。
- **皇家賭場（Real Casino de Murcia）：** {% pin "Real Casino de Murcia" %} {% tag "需門票", "price" %} 昔日富人俱樂部改造的博物館，內部裝潢揉合伊斯蘭與歐洲風格，極度華麗，拍照好地方。
- **博物館群：** 包含 **Museo de Santa Clara** {% pin "Museo de Santa Clara, Murcia" %}（修道院遺址）與 **Museo Arqueológico**（考古博物館）。修道院遺址是免門票的，開放時間內可自由進出。這裡只列舉兩個博物館，但其實還有許多的博物館。
- **Castillo de Monteagudo（耶穌像）：** {% pin "Castillo de Monteagudo, Murcia" %} {% tag "公車 22/50 路" %} 聳立於山頂的巨型耶穌像。目前僅能遠觀或抵達山腳，是穆爾西亞最有名的景致之一，可以在此觀看夕陽。
- **UMU 水族館（Acuario）：** {% pin "Acuario de la Universidad de Murcia" %} {% tag "門票約 1€", "price" %} 位於 Cuartel de Artillería，由大學管理的精緻水族館。

### 🛍️ 購物與休閒

- **英國宮百貨（El Corte Inglés）：** {% pin "El Corte Inglés Murcia" %} 位於市中心。百貨公司，還特別有一區是專門賣精緻伴手禮。
- **IKEA / Nueva Condomina：** {% pin "Centro Comercial Nueva Condomina, Murcia" %} {% tag "輕軌到底站" %} 最大的購物區，服飾品牌齊全，還有電影院、3C 用品商城、速食。
- **Casa del Libro：** {% pin "Casa del Libro Murcia" %} 位於市區的書店，不過英文書籍僅一櫃。
- **Jardín del Salitre：** {% pin "Jardín del Salitre, Murcia" %} 穆爾西亞有很多公園或花園可以散步，這是其中一個，可以挑離自己家近的，或者是有特別物種的去就好。

### 🌃 夜生活與社交

- **Taboo Bar：** {% pin "Taboo Bar Murcia" %} 酒吧，ESN（歐洲國際學生組織）常會在此舉辦活動，可以認識 UM 跟 UCAM 的很多人。
- **Karaoke La Gramola Centro：** {% pin "Karaoke La Gramola Murcia" %} KTV，但跟台灣的不一樣，外向想唱歌交朋友的人推薦去。
- **ODISEO：** {% pin "Odiseo Murcia" %} {% tag "輕軌/計程車" %} 穆爾西亞高端的綜合娛樂城，內有知名夜店、餐廳與賭場，裝潢極具現代感，但貌似要有朋友帶領。
{% endcard %}

## 2. 郊區景點（需搭巴士或火車）

{% grid %}
{% card "🌊 Cartagena (卡塔赫納)" %}
{% tag "ALSA 巴士 / FEVE 火車" %} 古羅馬遺跡與港口城市，午間在港口散步非常愜意，可在此花上一天休息。
{% endcard %}
{% card "🏖️ Águilas" %}
{% tag "火車 C-2 線" %} 擁有美麗的海灘，最著名的莫過於全西班牙前幾名的**嘉年華**（Carnaval）慶典。
{% endcard %}
{% card "🍷 Jumilla / Bullas" %}
{% tag "巴士" %} 著名的葡萄酒產區。Jumilla 以酒莊導覽聞名；Bullas 則推薦去 **Salto del Usero** 觀賞天然瀑布溪流。
{% endcard %}
{% card "🌸 Cieza" %}
{% tag "巴士/火車" %} 每年 2-3 月「桃花盛開（La Floración）」時美不勝收，是健行的好去處。
{% endcard %}
{% card "🌴 Alicante (阿利坎特)" %}
{% tag "火車 / 巴士" %} 鄰近的大城市，可在絕美海濱大道散步看日出，或往高處聖巴巴拉城堡（Castillo de Santa Bárbara）。
{% endcard %}
{% endgrid %}
