{% alert "📌 先看這裡", "info" %}
以下整理自 UCAM 國際處（ORI）官網的交換生資料（2026 年 11 月）。規定每年可能調整，請以學校最新通知為準。有課程相關問題，找你的 **UCAM 交換生協調老師（Exchange coordinator / tutor）**，而不是一般國際處窗口。
{% endalert %}

## 1. 整體流程

{% card %}
1. **線上預註冊（Pre-registration）**：在 UCAM 系統建立帳號，請用 **Gmail 等個人信箱**，不要用台灣學校的學校信箱。完成後會收到一組內部代碼。
2. **填寫交換生申請表**：用剛才的代碼登入，上傳照片、護照、成績單、語言證明、保險，以及 **Learning Agreement 草案**。送出後一定要看到「Your application has been submitted successfully」並截圖存證。
3. **等學校審核**：申請截止、資料驗證後，UCAM 會寄信告訴你如何**在線上完成正式的 Learning Agreement**，學校這時才會簽名。
4. **抵達後加退選**：學期初有一週 **add/drop week**，可以調整課程。
{% endcard %}

{% alert "📅 申請截止日" %}
第一學期約 **5 月 10 日**、第二學期約 **11 月 1 日**。實際日期以 UCAM 和台灣學校國際處的通知為準，通常台灣學校的校內截止日會更早。
{% endalert %}

## 2. Learning Agreement 到哪裡下載

所有表格都放在 UCAM 官網的 **[Incoming Students 頁面](https://www.ucam.edu/servicios/oficina-relaciones-internacionales/incoming-students)**。

{% card "📄 依你的交換計畫選擇表格" %}
申請表裡要選擇計畫類別，**台灣等亞洲學校通常屬於「UCAM USA/Overseas」**（歐洲學校是 Erasmus+，中南美洲是 UCAM Ibero）。

- **Overseas / 北美計畫用（台灣同學多半用這份）**：[learning_agreement_completo.docx](https://www.ucam.edu/sites/default/files/public/Oficina-relaciones-internacionales/Incoming-Students/Overseas-Program/learning_agreement_completo.docx)
- **Erasmus 用**：[learning_agreement.docx](https://www.ucam.edu/sites/default/files/public/Oficina-relaciones-internacionales/programa-erasmus-estudio/learning_agreement.docx)
- **填寫教學（英文 PDF）**：[Elaborate your learning agreement](https://www.ucam.edu/sites/default/files/public/Oficina-relaciones-internacionales/Incoming-Students/Erasmus-Students-Exchange-at-UCAM/elaborate-your-learning-agreement.pdf)
- **整體流程說明**：[Procedure（英文）](https://docs.google.com/document/d/e/2PACX-1vSOlUS-XcGsCoa5Om71TYvhzSLXx8kaSfjsMwjPrSoufTyRz3Jy7nhW5QDePWw1qg/pub)

不確定用哪份，可以問台灣學校國際處或寫信給 UCAM。
{% endcard %}

{% alert "⚠️ 注意", "warning" %}
- 申請時上傳的 Learning Agreement **只是草案**，不用先寄給 UCAM 老師或國際處簽名。
- UCAM **不使用 OLA（Online Learning Agreement）系統**。
- 選課前要先和**台灣學校的系上老師**確認可以抵免哪些課。
{% endalert %}

{% card "🎓 回台灣抵免學分要先準備" %}
- **出國前先確認：** 拿 UCAM 課程頁面的課程說明去問系上，哪些課可以抵哪門必修或選修，最好有書面紀錄。
- **學分換算：** UCAM 用的是歐洲 **ECTS** 學分，換算成台灣學分的比例**每間學校規定不同**，要問自己學校國際處或註冊組。
- **保留資料：** 每門課的**課程大綱（Guía docente）**、上課講義和成績單都要存好，回台辦抵免時常會用到。課程大綱在課程頁面就能下載（見下方第 4 節）。
{% endcard %}

## 3. 選課規則

- **只能選你交換那學期開的課**：第一學期為 9 月～1 月，第二學期為 1 月底～6 月。
- **學分**：每學期最多約 30 ECTS。一般課程每門 6 ECTS，兩週的密集課程為 2 ECTS。
- **至少 50～60% 的學分要來自同一個 UCAM 科系**，學校才能幫你分配主要的指導老師。
- **只能選大學部課程**，碩士課程不開放給交換生。
- **有英文授課的科系**：企管（BBA）、心理、運動科學、國際關係、牙醫、獸醫。教育、翻譯與口譯也有部分課程對英文使用者比較友善。其他科系大多是**西班牙文授課**。
- **熱門科系名額有限**（每門課約 5 個交換生名額）：翻譯與口譯、BBA、行銷、教育、心理、運動科學。名額依成績、與本科相關程度、英文程度分配，**有想修的課要早點申請**。
- **畢業專題（TFG）不能修**：可以列在 Learning Agreement 上，但成績單會顯示「Not attended」，沒有成績也沒有學分。
- **西班牙文課**（需付費）也要寫進 Learning Agreement，課程代碼欄留空。洽詢：escueladeidiomas@ucam.edu

{% card "🧪 特殊科系" %}
- **醫學**：只限在台灣念醫學系的同學，每門課最多 4 位交換生，不能參加醫院實習。
- **心理**：每門課每種語言最多 4 位，健康科學背景的同學優先；實習、畢業論文和 3、4 年級選修不開放。
- **護理、物理治療、職能治療實習**：抵達前要先寫信給 UCAM 協調老師確認名額。護理系有特別截止日，可能被分配到 Cartagena 校區。
- **需要語言證明**：西班牙文建議 B1（健康科學實習前必須）；英文授課課程建議 B2。
{% endcard %}

## 4. 怎麼查課程資訊

{% card "🔎 找課程與課程代碼" %}
1. 打開 UCAM 的[大學部課程目錄](https://www.ucam.edu/estudios?f=Grado)
2. 篩選條件選 **Modalidad：Presencial（實體）**、**Sede：Murcia**
3. 點進想修的科系，在 **課程規劃（Plan de estudios）** 裡找到課程
4. 點進單一課程，可以看到**課程代碼**和**課程說明**。Learning Agreement 上的課程名稱請照課程頁的寫法，盡量用西班牙文，必要時再附上英文
5. 也可以下載國際處整理的[課程清單（Excel）](https://www.ucam.edu/sites/default/files/public/Oficina-relaciones-internacionales/Incoming-Students/Erasmus-Students-Exchange-at-UCAM/listado_asignaturas-plan.xlsx)

填寫時科系名稱可以用縮寫，例如 ADE/BBA（企管）、CAFD/SC（運動科學）、TI（翻譯）、PSI/PSY（心理）。
{% endcard %}

## 5. 開學後：課表、教室與上課平台

{% card "🗓️ 課表與教室" %}
- **課表**：每個科系的網頁上都有 **「Horarios y exámenes」（課表與考試時間）** 的 PDF，依年級和學期分開。打開後可以看到每天每節課的時間和**教室代碼**，例如 `P8_1_A02`。
- **校園地圖**：教室分佈在校園內不同建築，可以用學校的 [Google 校園地圖](https://www.google.com/maps/d/viewer?hl=es&mid=1wfxoEnVk48CVOkJI8_otHKZVCNlWWvgu&ll=37.99122541130507%2C-1.1850123096888865&z=19)找到建築位置。第一次去上課建議提早出門找教室。
- **學年行事曆**：[2026-2027 學年行事曆（英文 PDF）](https://international.ucam.edu/sites/ucam.edu.en/files/documentos/calendario-academico-murcia-ingles.pdf)，上面有開學、假期和考試週。牙醫、心理、護理、醫學的開學日可能不同，請另外確認。
{% endcard %}

{% card "💻 Campus Virtual（線上學習平台）" %}
拿到 UCAM 帳號後，課程教材、作業繳交、公告、考試與行事曆都在 **[Campus Virtual](https://cv.ucam.edu/)**。學校信箱在 [correo.ucam.edu](http://correo.ucam.edu/)，登入或技術問題可找 [UCAM 資訊支援](https://soporte.ucam.edu/)。
{% endcard %}
