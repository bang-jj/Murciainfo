## 1. وسط المدينة والمناطق القريبة (بالترام أو الحافلة)

{% card "🏛️ الثقافة والمعالم" %}
- **كاتدرائية مرسية (Catedral de Murcia):** {% pin "Catedral de Murcia" %} {% tag "الدخول مجاني أثناء فتحها، والجولة المرشدة والبرج برسوم", "price" %} رمز المدينة. تُباع جولات الكاتدرائية والبرج بشكل منفصل، والجولات المرشدة **بالإسبانية فقط**.
- **الكازينو الملكي (Real Casino de Murcia):** {% pin "Real Casino de Murcia" %} {% tag "برسوم دخول", "price" %} نادٍ قديم للطبقة الراقية تحوّل إلى متحف. يمزج تصميمه الداخلي بين الطراز الإسلامي والأوروبي، وهو فخم جدًا ورائع للتصوير.
- **المتاحف:** منها **Museo de Santa Clara** {% pin "Museo de Santa Clara, Murcia" %} (بقايا دير، بآثار من العهد الأندلسي) و**Museo Arqueológico** (متحف الآثار). الدخول إلى Santa Clara مجاني خلال ساعات العمل. هذان مثالان فقط، ففي مرسية متاحف أخرى كثيرة.
- **قلعة مونتياغودو (تمثال المسيح):** {% pin "Castillo de Monteagudo, Murcia" %} {% tag "الحافلة 22 / 50" %} تمثال ضخم للمسيح على قمة تل. لا يمكن حاليًا إلا مشاهدته من بعيد أو الوصول إلى سفح التل، لكنه من أشهر مناظر مرسية ومكان جميل لمشاهدة الغروب.
- **حوض أسماك جامعة مرسية (Acuario):** {% pin "Acuario de la Universidad de Murcia" %} {% tag "نحو 1€", "price" %} حوض أسماك صغير ومعتنى به، تديره جامعة مرسية، في Cuartel de Artillería.

### 🛍️ التسوق والترفيه

- **El Corte Inglés:** {% pin "El Corte Inglés Murcia" %} متجر كبير في وسط المدينة، فيه قسم للهدايا التذكارية الراقية.
- **IKEA / Nueva Condomina:** {% pin "Centro Comercial Nueva Condomina, Murcia" %} {% tag "نهاية خط الترام" %} أكبر منطقة تسوق: ماركات ملابس كثيرة وسينما ومتجر إلكترونيات ووجبات سريعة.
- **Casa del Libro:** {% pin "Casa del Libro Murcia" %} مكتبة في المدينة، لكن الكتب الإنجليزية لا تملأ سوى رف واحد.
- **Jardín del Salitre:** {% pin "Jardín del Salitre, Murcia" %} في مرسية حدائق ومنتزهات كثيرة للتنزه، وهذه واحدة منها. اختر حديقة قريبة من بيتك أو فيها نباتات مميزة.

### 🌃 الحياة الليلية والتعارف

- **Taboo Bar:** {% pin "Taboo Bar Murcia" %} حانة تنظّم فيها شبكة ESN (شبكة طلاب إيراسموس) فعاليات كثيرة، ومكان جيد للتعرف على طلاب UM وUCAM.
- **Karaoke La Gramola Centro:** {% pin "Karaoke La Gramola Murcia" %} كاريوكي مفتوح وليس في غرف خاصة كما في آسيا. مناسب للاجتماعيين الذين يحبون الغناء والتعارف.
- **ODISEO:** {% pin "Odiseo Murcia" %} {% tag "ترام / سيارة أجرة" %} مجمّع الترفيه الراقي في مرسية، فيه نادٍ ليلي معروف ومطاعم وكازينو بتصميم عصري جدًا. يبدو أن الدخول أسهل برفقة شخص يعرف المكان.
{% endcard %}

## 2. رحلات خارج المدينة (بالحافلة أو القطار)

{% grid %}
{% card "🌊 قرطاجنة (Cartagena)" %}
{% tag "حافلة ALSA / قطار FEVE" %} مدينة ساحلية فيها آثار رومانية. التنزه في الميناء وقت الظهيرة ممتع جدًا، ومناسب لقضاء يوم هادئ.
{% endcard %}
{% card "🏖️ أغيلاس (Águilas)" %}
{% tag "قطار الخط C-2" %} شواطئ جميلة، وتشتهر خصوصًا بواحد من أشهر **الكرنفالات** في إسبانيا.
{% endcard %}
{% card "🍷 خوميا / بوياس" %}
{% tag "حافلة" %} منطقتان معروفتان بالكروم. تشتهر خوميا بجولات مصانع النبيذ، وفي بوياس يُنصح بزيارة **Salto del Usero** وشلاله الطبيعي.
{% endcard %}
{% card "🌸 ثييثا (Cieza)" %}
{% tag "حافلة / قطار" %} مذهلة في فبراير ومارس حين تزهر أشجار الخوخ (**La Floración**)، ومثالية للمشي في الطبيعة.
{% endcard %}
{% card "🌴 أليكانتي (Alicante)" %}
{% tag "قطار / حافلة" %} مدينة كبيرة قريبة. شاهد شروق الشمس من الكورنيش، أو اصعد إلى **قلعة سانتا باربرا**.
{% endcard %}
{% endgrid %}
