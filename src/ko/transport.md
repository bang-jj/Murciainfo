## 1. 트램(Tranvía)

트램은 무르시아에서 가장 편리한 교통수단입니다. 노선은 하나(L1)뿐이지만 교환학생이 자주 가는 곳 대부분을 지납니다.

{% grid %}
{% card "💰 요금" %}
| 종류 | 요금 |
|---|---|
| 1회권(Zona 1 / Zona 2) | 1.4€ / 1.5€ |
| **통합 교통카드(Bono Multitransporte)** | 0.5€ / 회 |
| **학생 정기권(Bono Campus)** | 12€ / 28일 무제한 |

<small>* 학생 정기권과 통합 교통카드는 학생증을 가지고 트램 회사 사무소에서 신청합니다.</small>
{% endcard %}

{% endgrid %}

{% alert "⚠️ 환승 주의:" %}
대학(Universidad) 방향으로 갈 때, UCAM 학생은 **Los Rectores-Terra Natura** 역에서 내려 **UCAM - Los Jerónimos** 행 지선으로 갈아타야 합니다. 돌아올 때도 마찬가지입니다(가끔 직행도 있습니다).
{% endalert %}

## 2. 버스(Autobús)

버스는 조금 복잡해서 시내버스(TMurciaBus)와 교외버스(TMP) 두 가지가 있습니다.

- **통합 교통카드 요금:** 1회 **0.8€**.
- **구별법:** 차량 앞에 **R** 표시가 있으면 보통 시내버스입니다.
- **UCAM 가는 버스:** 44번, 33번.

{% alert "🚨 주의:" %}
1. 행선지에 **UCAM - Los Jerónimos** 가 쓰여 있는지 꼭 확인하세요. 예를 들어 44E는 이민청 방향이라 학교에 가지 않습니다.
2. 버스는 자주 늦거나 오지 않으며, 구글 지도 정보도 완전히 정확하지 않습니다.
{% endalert %}
