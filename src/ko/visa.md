## 1단계: 예약(Cita Previa) 잡기

{% card %}
예약은 공식 포털에서 합니다: [외국인 업무 예약 포털](https://sede.administracionespublicas.gob.es/pagina/index/directorio/icpplus)

**절차:**

1. 주(provincia)에서 **Murcia** 선택.
2. 업무에서 **POLICIA-TOMA DE HUELLAS**(지문 등록) 선택.
3. 정보를 입력하고 예약 가능한 사무소 선택.

{% alert "💡 팁:" %}
TIE 예약은 불규칙하게 열리고 잡기가 매우 어렵습니다. 매일 아침 8~10시쯤 사이트를 확인하세요. 출국 전부터 시도한다면 스페인 서버로 VPN을 연결하는 것도 도움이 될 수 있습니다.
{% endalert %}
{% endcard %}

## 2단계: 필요 서류

{% card %}
- **EX-17 신청서**: 작성 및 서명 완료(원본 + 사본 1부).
- **유효한 여권**: 원본과 전체 페이지 사본(빈 페이지와 입국 도장 페이지 포함).
- **입학 허가서**: UCAM이 발급한 공식 입학 서류.
- **주소 등록 증명(Empadronamiento)**: 무르시아 시청에서 발급.<br><small>사무소: Calle Dr. Alonso de Espejo, 7, 30007 Murcia</small>
- **수수료 790-012**: 은행 납부 증명(약 16유로).
{% endcard %}

## 재외국민등록과 긴급 연락처

{% alert "📋 재외국민등록", "info" %}

{% endalert %}
