{% alert "📌 먼저 읽어 주세요", "info" %}
시간표와 요금은 계절에 따라 바뀝니다. 이 페이지는 2026년 11월 기준으로 정리했으니, 출발 전에 꼭 각 회사 공식 사이트에서 확인하세요. 기차와 저가항공은 **일찍 예약할수록 훨씬 쌉니다**. 직전에 사면 몇 배 비쌀 수 있습니다.
{% endalert %}

무르시아에는 주요 역이 두 곳 있습니다. 어느 쪽인지 확인하세요:

- **기차역: Murcia del Carmen**(Plaza de la Industria). 모든 기차가 여기에 섭니다.
- **버스터미널: Estación de Autobuses de Murcia**(San Andrés, Calle Sierra de la Pila 3). 장거리 버스와 공항버스가 여기서 출발합니다.

## 예매 앱 고르기

{% app "Trainline", "trainline", "https://www.thetrainline.com/" %}

- **교환학생에게 좋은 점:** 영어로 쓸 수 있고 **한국 카드도 잘 결제되는 편**입니다(Renfe 공식 사이트는 해외 카드를 거절할 때가 있습니다).
- **단점:** 보통 소액의 수수료가 붙습니다(결제 전에 표시). 열차를 정한 뒤 각 회사 공식 사이트와 비교해 보세요.
- **사용법:** 출발지(예: Madrid)와 도착지(Murcia), 날짜 입력 → 회사별 열차 비교 → 요금 선택 → 결제 → "내 티켓"에 전자 티켓이 표시됩니다.

## 1. 마드리드 → 무르시아

{% card "🚄 고속철도(추천)" %}
- **소요 시간:** 가장 빠르면 약 2시간 45분, 대부분 3~3.5시간.
- **운행사:** Renfe(AVE 등), OUIGO, iryo.
- **마드리드 출발역:** **Chamartín-Clara Campoamor** 또는 **Atocha**. 표에서 꼭 확인하세요.
- **요금:** OUIGO는 일찍 예약하면 약 9€부터. 직전에는 50€가 넘기도 합니다.
- **예매:** Renfe, OUIGO, iryo 공식 사이트나 앱, 또는 Trainline, Omio에서 비교.
{% endcard %}

{% card "🚌 장거리 버스(ALSA)" %}
- **소요 시간:** 약 5시간 20분~6시간 30분.
- **탑승 장소:** 마드리드 공항 **T4 버스터미널**(일부는 T1), 또는 시내의 Estación Sur.
- **요금:** 약 37€부터.
- **이런 분께:** 마드리드 공항에 막 도착해 짐이 많은 분. 갈아타지 않고 무르시아 버스터미널까지 갈 수 있습니다.
{% endcard %}

## 2. 바르셀로나 → 무르시아

바르셀로나는 무르시아에서 멀고 **현재 직행 기차가 없습니다**. 어떤 방법이든 반나절은 걸립니다.

{% grid %}
{% card "✈️ 비행기 + 버스(가장 빠름)" %}
바르셀로나에서 **알리칸테(ALC)** 까지 약 1시간 10분, Vueling 등이 하루 여러 편 운항합니다. 그다음 알리칸테 공항에서 버스로 무르시아까지(4번 항목 참고).

Volotea는 무르시아 공항(RMU)으로도 운항하지만 편수가 적습니다.
{% endcard %}
{% card "🚄 기차(1회 환승)" %}
가장 빠르면 약 6.5시간, 보통 7~8시간 이상. 가격 변동이 크니 일찍 예약하세요.
{% endcard %}
{% card "🚌 장거리 버스(ALSA)" %}
**Estació del Nord** 버스터미널에서 약 10~12시간. 야간 버스를 타면 하룻밤 숙박비를 아낄 수 있습니다.
{% endcard %}
{% endgrid %}

## 3. 발렌시아 → 무르시아

- **버스(ALSA):** 발렌시아 버스터미널에서 약 4.5시간. 가장 저렴합니다.
- **기차:** Estació del Nord에서 직행 또는 알리칸테 환승, 약 4.5~5.5시간.
- **발렌시아 공항에서:** 지하철 **3호선이나 5호선**을 타고 Xàtiva 역으로(바로 옆이 Estació del Nord). 고속철도 Joaquín Sorolla 역은 Àngel Guimerà에서 1호선이나 2호선으로 갈아타 Jesús 역에서 내립니다.

## 4. 무르시아 근처 공항(해외여행용)

{% card "🛫 알리칸테 공항 ALC(해외여행에 가장 추천)" %}
{% tag "약 70km" %} {% tag "버스 약 55분" %}

근처에서 **노선이 가장 많은** 공항으로, 2026년 여름 **30개국 141개 도시**에 취항합니다. Ryanair, Vueling, easyJet, Wizz Air, Volotea 등 저가항공이 있어 유럽 여행 대부분은 여기서 출발하는 것이 편합니다.

**가는 법:**

- **ALSA 직행 버스(가장 간편):** 무르시아 버스터미널 ↔ 알리칸테 공항, 약 55분, 약 8€, 하루 십여 편. 공항 정류장은 터미널 2층(출국층) 밖 오른쪽입니다.
- **버스 + 기차:** 공항에서 **C6 버스**(3.85€, 약 20분 간격)로 알리칸테 기차역까지 간 뒤 기차로 Murcia del Carmen까지(45분~1시간 남짓).
{% endcard %}

{% card "🛫 무르시아 공항 RMU(Corvera)" %}
{% tag "약 27km" %} {% tag "버스 1.85€", "price" %}

시내에서 가장 가깝지만 노선이 적습니다. 7개국 약 20개 노선으로 **주로 영국**(런던, 맨체스터 등)이며, 더블린, 바르셀로나, 카나리아 제도, 일부 프랑스·이탈리아·모로코 노선이 있습니다.

**가는 법:** 무르시아 버스터미널에서 공항행 시내버스가 있습니다(편도 1.85€, 하루 약 10편). 택시도 이용할 수 있습니다. 계절에 따라 시간표가 바뀔 수 있으니 미리 확인하세요.
{% endcard %}

{% card "🛫 발렌시아 공항 VLC" %}
{% tag "대중교통 약 4~5시간" %}

2026년 여름 110개 노선으로 RMU보다 선택지가 많지만 무르시아에서 멉니다. 알리칸테에서 원하는 곳으로 가는 편이 없을 때나 발렌시아 여행을 겸할 때 좋습니다.
{% endcard %}

{% card "🛫 마드리드 공항 MAD(귀국·장거리 노선)" %}
한국 등 아시아나 미주로 가는 장거리 노선은 보통 마드리드에서 출발합니다(또는 알리칸테에서 유럽 대도시로 가서 환승). 무르시아에서는 **ALSA 직행 버스로 T4까지** 가거나, 고속철도로 마드리드에 간 뒤 지하철이나 근교 열차로 갈아탑니다.
{% endcard %}

## 5. 해외여행 팁

{% alert "⚠️ TIE를 아직 받지 못했다면 주의", "warning" %}
TIE 발급 중에 솅겐 지역 밖(영국, 모로코 등)으로 나가면 스페인으로 돌아올 때 문제가 생길 수 있습니다. 여행 전에 비자와 체류 상태를 확인하고, 불확실하면 이민청이나 학교 국제처에 문의하세요.
{% endalert %}

- **솅겐 지역 내 여행:** 출입국 심사는 없지만 **여권**(과 TIE)은 꼭 챙기세요. 항공사가 탑승할 때 신분증을 확인합니다.
- **저가항공 수하물 규정은 엄격:** 보통 작은 가방 하나만 무료이고, 기내용 캐리어와 위탁 수하물은 따로 사야 합니다. 늦게 살수록 비싸고, 크기를 넘으면 탑승구에서 요금을 냅니다.
- **Ryanair는 온라인 체크인 필수:** 공항 카운터에서 체크인하면 요금이 붙습니다.
- **비교 도구:** 항공권은 Skyscanner나 Google 항공편, 기차·버스는 Trainline이나 Omio로 비교한 뒤 공식 사이트에서 사면 더 싼 경우가 많습니다.

## 6. 한국으로 가는 항공편

마드리드–인천 직항이 운항되는 시기가 있지만, 무르시아 근처에서는 보통 마드리드, 유럽 대도시(파리, 프랑크푸르트, 암스테르담 등)나 중동(도하, 두바이, 이스탄불)을 경유합니다. 학기말에는 비싸지니 일찍 예약하세요.
