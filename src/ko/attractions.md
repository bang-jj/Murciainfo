{% card "🏛️ 문화와 랜드마크" %}
- **무르시아 대성당(Catedral de Murcia):** {% pin "Catedral de Murcia" %} {% tag "개방 시 무료 입장, 가이드 투어와 종탑은 유료", "price" %} 도시의 상징. 대성당과 종탑 투어는 따로 판매하며, 가이드는 **스페인어로만** 진행됩니다.
- **레알 카지노(Real Casino de Murcia):** {% pin "Real Casino de Murcia" %} {% tag "유료", "price" %} 옛 상류층 클럽을 개조한 박물관. 이슬람과 유럽 양식이 섞인 내부가 매우 화려해 사진 찍기 좋습니다.
- **박물관:** **Museo de Santa Clara** {% pin "Museo de Santa Clara, Murcia" %}(수도원 유적)와 **Museo Arqueológico**(고고학 박물관) 등. 산타 클라라는 개방 시간에 무료로 들어갈 수 있습니다. 이 밖에도 박물관이 많습니다.
- **몬테아구도 성(예수상):** {% pin "Castillo de Monteagudo, Murcia" %} {% tag "버스 22 / 50번" %} 언덕 위의 거대한 예수상. 지금은 멀리서 보거나 산기슭까지만 갈 수 있지만, 무르시아에서 가장 유명한 풍경 중 하나로 노을 보기에 좋습니다.
- **UMU 수족관(Acuario):** {% pin "Acuario de la Universidad de Murcia" %} {% tag "약 1€", "price" %} Cuartel de Artillería에 있는, 무르시아 대학교가 운영하는 작지만 알찬 수족관.

### 🛍️ 쇼핑과 여가

- **엘 코르테 잉글레스(El Corte Inglés):** {% pin "El Corte Inglés Murcia" %} 시내 백화점. 고급 기념품 코너도 있습니다.
- **IKEA / Nueva Condomina:** {% pin "Centro Comercial Nueva Condomina, Murcia" %} {% tag "트램 종점" %} 가장 큰 쇼핑 지역. 옷 브랜드가 다양하고 영화관, 전자제품 매장, 패스트푸드가 있습니다.
- **Casa del Libro:** {% pin "Casa del Libro Murcia" %} 시내 서점. 다만 영어책은 한 칸뿐입니다.
- **Jardín del Salitre:** {% pin "Jardín del Salitre, Murcia" %} 무르시아에는 산책할 공원과 정원이 많은데 그중 하나입니다. 집 근처나 특별한 식물이 있는 곳을 골라 가 보세요.

### 🌃 밤문화와 교류

- **Taboo Bar:** {% pin "Taboo Bar Murcia" %} ESN(유럽 국제학생 단체)이 자주 행사를 여는 바. UM과 UCAM 학생을 많이 만날 수 있습니다.
- **Karaoke La Gramola Centro:** {% pin "Karaoke La Gramola Murcia" %} 노래방이지만 한국처럼 방이 따로 있지 않습니다. 외향적이고 노래하며 친구를 사귀고 싶은 분께 추천.
- **ODISEO:** {% pin "Odiseo Murcia" %} {% tag "트램/택시" %} 무르시아의 고급 복합 엔터테인먼트 시설. 유명 클럽, 레스토랑, 카지노가 있고 인테리어가 매우 현대적입니다. 아는 사람과 함께 가는 편이 들어가기 쉬운 듯합니다.
{% endcard %}

## 2. 근교 여행(버스·기차)

{% grid %}
{% card "🌊 카르타헤나(Cartagena)" %}
{% tag "ALSA 버스 / FEVE 기차" %} 고대 로마 유적이 있는 항구 도시. 한낮에 항구를 산책하기 좋아 하루 쉬어 가기 좋습니다.
{% endcard %}
{% card "🏖️ 아길라스(Águilas)" %}
{% tag "기차 C-2선" %} 아름다운 해변이 있고, 스페인 최고 수준의 **카니발(Carnaval)** 로 유명합니다.
{% endcard %}
{% card "🍷 후미야 / 부야스" %}
{% tag "버스" %} 유명한 와인 산지. 후미야는 와이너리 투어로 유명하고, 부야스에서는 천연 폭포 **Salto del Usero** 를 추천합니다.
{% endcard %}
{% card "🌸 시에사(Cieza)" %}
{% tag "버스/기차" %} 매년 2~3월 복숭아꽃이 피는 시기(**La Floración**)에 장관을 이루며, 하이킹하기 좋습니다.
{% endcard %}
{% card "🌴 알리칸테(Alicante)" %}
{% tag "기차/버스" %} 가까운 대도시. 해변 산책로에서 일출을 보거나 언덕 위 **산타 바르바라 성**에 올라가 보세요.
{% endcard %}
