## 1. 방 찾는 방법

지인 소개 외에 스페인에서 가장 많이 쓰는 것은 **idealista** 앱입니다.

{% app "idealista", "idealista", "https://www.idealista.com/" %}
- **언어:** 영어나 중국어로 설정할 수 있어 언어 걱정이 적습니다.
- **검색 방법:** 지도 검색, 원하는 범위를 그려서 검색, 전화 연락을 지원합니다.
- **방 종류:** 교환학생 대부분은 셰어하우스의 **개인실(Habitación)** 을 구합니다.
{% endapp %}

## 2. 스페인 셰어하우스는 이렇습니다

{% card "🏡 한국 자취방과 다른 점" %}
- **공용 주방:** 거의 항상 있고 화구, 오븐, 전자레인지, 조리도구가 갖춰져 있습니다. **냉장고는 한 사람당 한 칸**씩 나눠 쓰는 게 보통입니다.
- **공용 욕실:** 여러 명이 욕실 하나를 같이 쓰는 경우가 많고, 개인 욕실이 있는 방은 드물고 비쌉니다.
- **세탁기는 있지만 건조기는 드묾:** 빨래는 베란다나 건조대에 말립니다.
- **공과금(gastos):** 물, 전기, 가스, 와이파이가 월세에 **포함되는지** 꼭 확인하세요. 포함되지 않으면 보통 룸메이트끼리 나눕니다.
- **보증금(fianza):** 보통 **월세 1개월치**로, 한국처럼 큰 보증금은 없습니다. 퇴실 때 문제가 없으면 돌려받습니다.
- **온돌이 없어요:** 여름은 35도를 넘는 날이 많고, 겨울에는 **난방이 없는 집**이 많아 실내가 춥습니다. 에어컨(aire acondicionado)과 난방기구가 있는지 확인하세요.
{% endcard %}

## 3. 연락과 계약 팁

{% app "WhatsApp", "whatsapp", "https://www.whatsapp.com/" %}
스페인에서는 집주인, 룸메이트, 수업 단톡방 모두 거의 WhatsApp을 씁니다. 출국 전에 설치해 두세요.
{% endapp %}

- **WhatsApp 사용:** 메시지는 스페인어로 쓰는 것이 좋습니다. 집주인이 하루 동안 답이 없으면 정중하게 다시 연락하세요.
- **계약 조건:** 성별 제한(여성만 등)이 있는지 확인하세요. 많은 집주인이 1년 이상 장기 계약을 선호합니다.
- **직접 방문:** 사진과 실제가 다를 수 있으니 결정 전에 꼭 직접 보세요.
- **결제 방법:** 현금인지 계좌이체인지 확인하세요. 이체하려면 보통 스페인 은행 계좌가 필요합니다.

## 4. 스페인 임대 상식(문화 차이)

{% alert %}
- **방문 잠금장치:** 셰어하우스의 방문에는 **잠금장치가 없는** 경우가 많습니다. 사생활이 중요하다면 미리 물어보세요.
- **층수 세는 법:** 층은 **Bajo(지상층) → 1 → 2…** 순서입니다. 한국의 1층이 Bajo이므로, 현지의 "1층"은 **한국의 2층**입니다.
- **집 안에서도 신발:** 스페인에서는 보통 집 안에서도 신발을 신습니다. 벗고 싶다면 실내화를 준비하세요.
- **주방은 필수:** 스페인은 외식비가 비싸니 주방이 있는 집을 고르세요. 대부분 갖춰져 있습니다.
{% endalert %}

## 5. 추천 지역

시내 중심(Centro) 외에 방이 많은 지역:

- **인기 지역:** Guadalupe, La Ñora, Senda de Granada, Espinardo.
- **개인 추천:** 생활 편의와 사교를 생각하면 시내 중심(Centro)이 가장 좋습니다.
- **대안:** 예산이 빠듯하거나 시내에 방이 없다면 Guadalupe나 La Ñora(외곽 지역).
