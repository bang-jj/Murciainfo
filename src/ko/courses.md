## 1. 전체 과정

{% card %}
1. **온라인 사전 등록:** UCAM 시스템에서 계정을 만듭니다. 소속 대학 메일이 아니라 **Gmail 같은 개인 메일**을 쓰세요. 완료하면 내부 코드를 받습니다.
2. **교환학생 신청서:** 그 코드로 로그인해 사진, 여권, 성적표, 어학 증명, 보험, **Learning Agreement 초안**을 올립니다. 제출 후 "Your application has been submitted successfully"가 보이는지 확인하고 캡처해 두세요.
3. **심사 대기:** 마감 후 등록이 승인되면, **정식 Learning Agreement를 온라인으로 완성하는 방법**을 메일로 받습니다. UCAM은 이때 서명합니다.
4. **도착 후 수강 정정:** 학기 초에 **add/drop week**가 있어 수업을 조정할 수 있습니다.
{% endcard %}

{% alert "📅 신청 마감" %}
1학기는 **5월 10일경**, 2학기는 **11월 1일경**입니다. 실제 날짜는 UCAM과 소속 대학의 안내를 따르세요. 소속 대학의 교내 마감은 보통 더 이릅니다.
{% endalert %}

## 3. 수강 규칙

- **교환 학기에 열리는 수업만:** 1학기는 9월~1월, 2학기는 1월 말~6월.
- **학점:** 학기당 최대 약 30 ECTS. 대부분 6 ECTS, 2주 집중 과정은 2 ECTS.
- **ECTS의 50~60% 이상은 UCAM의 한 전공에서** 들어야 주 지도교수를 배정받을 수 있습니다.
- **학부 수업만**: 석사 과정 수업은 교환학생에게 열려 있지 않습니다.
- **영어 수업이 있는 전공:** 경영학(BBA), 심리학, 스포츠과학, 국제관계, 치의학, 수의학. 교육학, 번역·통역에도 영어로 듣기 쉬운 수업이 일부 있습니다. 나머지 전공은 대부분 **스페인어** 수업입니다.
- **인기 전공은 정원 제한**(수업당 교환학생 약 5명): 번역·통역, BBA, 마케팅, 교육학, 심리학, 스포츠과학. 성적, 전공 관련성, 영어 실력으로 배정되니 **일찍 신청**하세요.
- **졸업 프로젝트(TFG)는 평가되지 않습니다:** Learning Agreement에 넣을 수는 있지만 성적표에는 "Not attended"로 표시되고 성적과 학점이 없습니다.
- **스페인어 수업**(유료)도 Learning Agreement에 적고, 과목 코드는 비워 둡니다. 문의: escueladeidiomas@ucam.edu

{% card "🧪 특별 규정이 있는 전공" %}
- **의학:** 소속 대학에서 의학을 전공하는 학생만 가능. 수업당 최대 4명, 병원 실습 불가.
- **심리학:** 수업·언어당 최대 4명, 보건계열 학생 우선. 실습, 졸업 논문, 3·4학년 선택 과목은 불가.
- **간호·물리치료·작업치료 실습:** 도착 전에 UCAM 코디네이터에게 메일로 자리를 확인하세요. 간호는 별도 마감이 있고 카르타헤나 캠퍼스로 배정될 수도 있습니다.
- **어학 요건:** 스페인어 B1 권장(보건계열 실습 전 필수), 영어 수업은 B2 권장.
{% endcard %}

## 4. 수업 정보 찾는 법

{% card "🔎 수업과 과목 코드 찾기" %}
1. UCAM [학부 과정 목록](https://www.ucam.edu/estudios?f=Grado) 열기
2. **Modalidad: Presencial(대면)**, **Sede: Murcia** 로 필터
3. 원하는 전공 페이지에서 **교과과정(Plan de estudios)** 의 수업 찾기
4. 수업 페이지에서 **과목 코드**와 설명 확인. Learning Agreement의 과목명은 그 페이지 표기대로(가능하면 스페인어, 필요하면 영어 병기) 적기
5. 국제처가 정리한 [과목 목록(Excel)](https://www.ucam.edu/sites/default/files/public/Oficina-relaciones-internacionales/Incoming-Students/Erasmus-Students-Exchange-at-UCAM/listado_asignaturas-plan.xlsx) 도 받을 수 있습니다

전공명은 약어로 써도 됩니다(예: ADE/BBA 경영학, CAFD/SC 스포츠과학, TI 번역, PSI/PSY 심리학).
{% endcard %}

{% card "🗓️ 시간표와 강의실" %}
- **시간표:** 전공의 **Plan de Estudios** 페이지에서 「Horarios y exámenes」 → 「Horarios y Planificación」으로 학년별 온라인 시간표를 엽니다. 수업 시간, 과목 코드, **강의실**(예: `Aula P8_1_A06` = 8번 건물 1층 6번 강의실)이 나옵니다. 위 그림 참고.
- **캠퍼스 지도:** 강의실은 여러 건물에 나뉘어 있습니다. UCAM의 [구글 캠퍼스 지도](https://www.google.com/maps/d/viewer?hl=es&mid=1wfxoEnVk48CVOkJI8_otHKZVCNlWWvgu&ll=37.99122541130507%2C-1.1850123096888865&z=19)로 위치를 확인하고, 첫 수업 날은 일찍 나가세요.
- **학사 일정:** [2026-2027 학사 일정(영어 PDF)](https://international.ucam.edu/sites/ucam.edu.en/files/documentos/calendario-academico-murcia-ingles.pdf). 개강, 방학, 시험 기간이 나와 있습니다. 치의학·심리학·간호·의학은 일정이 다를 수 있으니 따로 확인하세요.
{% endcard %}
